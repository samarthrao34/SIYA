# SIYA data flows

What leaves the device, which service receives it, and what is stored. Derived
from the code at the time of writing; the line references point at the code
that does each thing. The consent screen and Privacy Center show a summary
of the same information (`src/components/DataDisclosure.tsx`), filtered to
the flows active in the current setup (`GET /api/privacy/status`).

Keep this file, `DataDisclosure.tsx` and the README's privacy section in sync
whenever a data flow changes, and bump `CONSENT_VERSION` in
`src/components/ConsentGate.tsx` so existing users are asked again.

## Desktop app, Gemini mode (default)

| Data | When | Sent to | Code |
| --- | --- | --- | --- |
| Microphone audio (16 kHz PCM) | While a voice session is open | Google Gemini Live | `server/index.ts` (`msg.audio` → `sendRealtimeInput`) |
| Typed messages | When sent | Google Gemini Live | `server/index.ts` |
| SIYA's replies (audio and text) | Every turn | Generated by Google Gemini Live | `server/index.ts` |
| **Camera still**: JPEG, max 480 px, quality 0.6 | Every 2.5 s while the camera is on | Google Gemini Live, as video input | `src/components/MainExperience.tsx` (`sendCameraFrame`), `server/index.ts` (`msg.type === "video"`) |
| **Facial-expression label and confidence** (e.g. `sad 0.62`) | With camera stills; turned into a model prompt when it changes | Google Gemini Live, as text | `src/vision/emotionDetector.ts`, `server/index.ts` (`internal.user_emotion_changed`) |
| **Behaviour state and cues** (e.g. tired: yawning, head in hands) | With camera stills; turned into a model prompt in quiet stretches | Google Gemini Live, as text | `src/vision/behaviorAnalyzer.ts`, `server/index.ts` (behaviour block) |
| Screen images: JPEG, max 720 px | While screen sharing is on, and when SIYA uses `viewScreen`/screenshot tools | Google Gemini Live | `src/components/MainExperience.tsx`, `server/screenVision.ts` |
| **Active app name and window title** | Proactive check-ins while desktop awareness is on (default: on; `SIYA_ENABLE_DESKTOP_AWARENESS=false` disables) | Google Gemini Live, as text | `server/cognition/desktopPerception.ts`, `server/index.ts` (`buildInitiativePrompt`) |
| Last ≤ 12 dialogue turns and current memories | After turns, to consolidate memories | Google Gemini (`generateContent`) | `server/memory.ts` (`processConversationSlice`) |
| Relevant stored memories | At session start | Google Gemini Live (system prompt) | `server/index.ts` |
| Goal objective, constraints, success criteria | When a goal is planned (`POST /api/goals/:id/plan`) | Google Gemini (`generateContent`) | `server/cognition/planner.ts` |
| **What the user says or types** (turns ≥ 12 characters, first 2,000 characters) | After each turn, only if `TYPESAFE_API_KEY` is set and `SIYA_TEXT_EMOTION` is not `off` | TypeSafe (`api.typesafe.ai`) | `server/textEmotion.ts`, `server/index.ts` (`queueTextEmotion`) |

The Gemini key is the user's own. On the free tier, Google may use submitted
content to improve its products.

## Desktop app, local mode (`SIYA_BRAIN=local`)

Conversation, camera and screen frames go to the local LLM endpoint
(`SIYA_LOCAL_LLM_URL`, default `127.0.0.1`) and the local voice service. Text
emotion and memory consolidation are skipped.

| Data | When | Sent to | Code |
| --- | --- | --- | --- |
| SIYA's reply text | Each spoken sentence, with the default `SIYA_TTS_ENGINE=edge` | Microsoft Edge read-aloud service | `services/local_voice/server.py` |
| Goal objective etc. | When a goal is planned and a Gemini key is saved | Google Gemini | `server/cognition/planner.ts` (not gated by brain mode) |

`SIYA_TTS_ENGINE=kokoro` keeps speech synthesis fully offline.

## Tool calls (either mode, when SIYA uses the tool)

| Data | Sent to | Code |
| --- | --- | --- |
| Latitude and longitude | Open-Meteo (weather) | `server/api-hub/builtInAdapters.ts` |
| Currency codes | Frankfurter (exchange rates) | `server/api-hub/builtInAdapters.ts` |
| Nothing user-specific | The Space Devs (launches); GitHub (public-APIs catalogue download) | `server/api-hub/` |
| Search query | YouTube (`/api/youtube-search`) | `server/index.ts` |
| Requested URL | That website (`/api/proxy`, web proxy) | `server/index.ts` |
| Search query or URL | Opened in the user's browser | `services/desktop_agent/tools_websites.py` |
| Fixed gesture prompts (no user data) | Motion service, only if `SIYA_MOTION_SERVICE_URL` is set | `src/character/characterEngine.ts`, `server/index.ts` |

## Mobile app

The Android app talks to Gemini directly from the phone with the user's key.

| Data | When | Sent to | Code |
| --- | --- | --- | --- |
| Microphone audio, typed messages | During a session | Google Gemini Live | `mobile/app/mobileLiveSession.ts` |
| Camera still (JPEG) | Every 5 s while the camera is on | Google Gemini Live | `mobile/app/mobileLiveSession.ts` (`sendCameraFrame`) |
| Memory cards, profile facts, recall queries (the user's words) | When SIYA saves or recalls memories | The owner's self-hosted memory server (`VITE_SIYA_MEMORY_URL`), over a private network | `mobile/app/memoryClient.ts` |
| Currency codes | Currency tool | Frankfurter | `mobile/app/mobileLiveSession.ts` |

## Processed only on the device

- Facial landmarks and blendshapes, hand landmarks (MediaPipe, WASM). Only the
  resulting labels leave the device, as listed above.
- Crisis-language detection (`server/safety.ts`).
- OCR of screenshots (Tesseract, desktop agent).
- Voice activity detection and Kokoro speech synthesis (local mode).

## Stored on the device

Location: `SIYA_DATA_DIR` (Electron `userData` when packaged).

| File | Contents | Encrypted |
| --- | --- | --- |
| `memories.json`, `cognition/memories.v1.json` | Long-term memories | Yes, when a data key is present (AES-256-GCM, key in OS keyring) |
| `cognition/goals.v1.json` | Goals | Same as above |
| `cognition/last-session.json` | Notes from the last session | Same as above |
| `cognition/skills.v1.json` | Learned skills: tool steps with their arguments (can include file names or text to type) | No |
| `settings.json` | Settings, consent record | No |
| `secrets.json` | Gemini API key | No; file mode `0600` |
| `logs/commands.log` | Tool names and argument **names**, settings changes, screen-vision events, crisis-card events | No |
| `logs/errors.log`, `logs/startup.log` | Errors (can include file names or short agent responses), startup events | No |
| `api-hub/*.json` | Public API catalogue and adapters | No (not personal) |

Not stored: camera images, microphone audio, conversation transcripts (the
dialogue history is in memory only). Screenshots are written to disk only by
the `saveScreenshot` tool, when the user asks.

**Delete all my data** (`POST /api/privacy/delete-all`) erases memories,
goals and last-session notes, truncates logs and resets consent. It keeps
settings, the Gemini key, learned skills and the API-hub catalogue, and it
cannot delete anything already sent to a third party.
